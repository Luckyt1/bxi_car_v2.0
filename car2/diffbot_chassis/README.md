# ISWV 底盘工作区

核心包为 `src/chassis`。构建、接线、校准与主程序调用方式见 [项目说明](../readme.md)。

## 单个转向轮方向确认

在项目根目录运行 `sudo -E bash start_steering_direction_test.sh`。先停掉所有其他电机程序、架空固定车辆、检查机械限位并准备独立急停。输入 CALIBRATE 后先执行现有两两碰限校准并四轮回中，再在同一次上电中依次测试前左、后左、后右、前右。每轮输入 `1` 并回车才以输出轴 2 RPM 正向点动 +50°，不同时转动四轮，不修改 inverted。

每轮点动后输入 `1`（从车顶俯视顺时针）或 `2`（逆时针），然后回车；`0`（未动）、`3`（动错轮）、`q`（取消）都会中止流程。仍兼容原来的 MOVE / CW / CCW / NONE / WRONG / Q 输入，日志继续使用英文方向标记。复制最终四轮汇总或 `DIRECTION_TEST`、`DIRECTION_RESULT`、`STEERING_OBSERVATION` 给维护者，再根据实测方向决定是否调整配置。底盘数学约定下正角期望俯视逆时针，编码器增加本身不代表实际方向正确。

点动使用本次校准的实时中位和正负端点，开始前要求反馈距中位不超过约 0.5°，目标必须位于实测限位内收安全余量的范围。估算力矩达到 1 N·m（或更低的配置安全阈值）、驱动故障、异常位移、超时均停止。等待回答期间四轮仍上电保持位置，每次输入最多等待 120 秒；全部完成或 Ctrl+C 后停止并断电，不自动把点动后的轮子转回中位。校准阶段沿用现场搜索速度和力矩参数，不能因点动低速而忽略校准碰限风险。独立旧版 `steering_direction_test CONFIG WHEEL DELTA_DEG` 程序仍保留，但本脚本不再使用它。

底盘使用 ISWV 转向/行进电机；意优工具保留给上装。当前底盘不包含 Modbus 升降柱。

## 连续转向与限位保护

校准搜索循环目标周期为 20 ms，包含本轮同步 SDO 读取耗时；若通信耗时超过周期，不追加等待。实际检测周期仍受通信和调度影响，并非硬实时 50 Hz。到达接触力矩即撤销该轴速度，两轴停下后的 200 ms 等待保留；搜索速度和力矩阈值不因此改变。

平移和旋转同时参与四轮解算。运行时使用转向 TPDO 实际位置选择机械范围内的等效角度（必要时反转行进轮），不跨硬限位取模走捷径。每次校准保留四轮正负端点，运行范围在端点内收 `steering_limit_margin_rad`（默认 5°），并与配置最大角度取交集。

小角度调整允许边走边转；误差越大，行进速度越低。误差达到 `drive_alignment_stop_rad`（默认 0.5 rad）时先停车再对齐，控制循环不阻塞。转向目标变化限速默认 0.5 rad/s，旋转指令加速度默认 0.8 rad/s²。行进轮反向前先减速至零。

转向 TPDO1/3 超过 250 ms、实际编码器越过安全边界、驱动器故障或对齐超时均停机。启动日志打印各轮安全范围；边界异常日志包含轮名、实际编码器和允许范围。软件边界依赖校准准确性，不能替代机械限位和独立急停；首次验证应架空车体、低速进行。
